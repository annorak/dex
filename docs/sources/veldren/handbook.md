# Veldren People Services client setup handbook

Issued September 1, 2025.

## 1. Open the client record

Open one case for each signed client agreement.
Keep the client's sites, employees, and requested services under that case.
Each employee belongs to one site.
Use the identifiers in the supplied roster.
The agreement names the client sponsor.

## 2. Check each requested service

A site can request payroll setup, benefits setup, or both.
For payroll setup, check each employee's identifier and display name.
Check the site's pay frequency and payroll cutover date.
For benefits setup, check the plan code, eligibility group, and site contact.
A site requesting both services must pass both checks.
Do not request fields for a service the site has not ordered.

## 3. Obtain missing information

Ask the sponsor for missing or conflicting information.
Name the affected site and fields.
The response is due by the end of the third calendar day after the request.
Keep a late request open and bring it to the onboarding coordinator's attention.
Record the response against its original request.
Do not supply a missing value yourself.

## 4. Prepare and activate the client

Mark a site ready after all its requested services pass their checks.
Prepare the client setup summary after every site is ready.
The onboarding coordinator may activate a client when the summary is complete.
Activation creates the client's configuration in the setup system.

## 5. Check unfamiliar roster statuses

Ask the service owner about an unfamiliar status before using the affected records.
The clarification is due within one calendar day.
Keep the affected work pending until the answer resolves it.
